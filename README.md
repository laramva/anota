# Anota

Caderno digital para estudar no iPad com Apple Pencil: caneta com pressão, marca-texto, borracha, laço, formas, texto, imagens, PDFs, gravação de áudio sincronizada com a escrita, organização por matéria e tema, funcionamento offline e sincronização com Supabase.

Abra no Safari do iPad e use **Compartilhar → Adicionar à Tela de Início**.

As notas ficam no aparelho (IndexedDB) e, com login, numa cópia na nuvem protegida por regras de acesso por usuário (RLS). O banco é criado com `supabase/schema.sql`.
